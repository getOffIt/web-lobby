# Block Rush Play

A playable 3D Roblox-style obstacle course that runs in the browser.

## Play Locally

```sh
pnpm install --ignore-workspace
pnpm dev
```

Then open:

```text
http://127.0.0.1:5173/
```

## Controls

- WASD or arrow keys to move
- Space to jump
- Shift to sprint
- Reset button to return to the current checkpoint

## Win Conditions

- Reach the glowing finish portal
- Or collect all 21 coins
